# Wave planning

Score candidates on business criticality, responsibility complexity, dependency count, consumer count, behavior-test coverage, data sensitivity, transaction semantics, change window, owner capacity, target-platform readiness, and retirement benefit.

- Wave 0: inventory, foundations, shared patterns.
- Wave 1: low-risk gateway-dominant APIs with useful representativeness.
- Wave 2: one example from each integration pattern.
- Wave 3+: repeatable factory waves by domain and dependency cluster.
- Final: shared domains, platform dependencies, license/infrastructure closure.
