# Mule-to-AKS integration pattern

Extract a bounded integration capability with a contract, owner, stateless design where possible, external state/idempotency where required, approved messaging/connectors, workload identity, secrets, retries/timeouts, OpenTelemetry, golden tests, resource controls, autoscaling, PDB, runbook, and independent release lifecycle.

AKS is a runtime, not an integration product; shared libraries, templates, support, and platform services must be intentional.
