# Migration factory

The factory provides intake, discovery scanner/manual review, classification, target patterns, OpenAPI and service templates, golden-test harness, API operations pipelines, security review, observability/runbooks, cutover/reconciliation, benefit tracking, and decommission certification.

Quality is measured by lead time, escaped behavior defects, rollback rate, SLO, incident rate, automated evidence coverage, retired dependencies, and realized run-cost change—not simply migrated API count.
