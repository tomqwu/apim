# Apigee assessment

Apigee is the benchmark for mature enterprise API products, proxy policies, lifecycle, analytics, developer ecosystems, and governance. Score Apigee X and Apigee Hybrid separately.

**Confirmed:** Apigee Hybrid uses a Google-operated management plane and a customer-managed Kubernetes runtime. API traffic is processed in the runtime plane. The runtime includes message processors, synchronizer, Cassandra, and MART; it can continue processing with locally synchronized configuration when management connectivity is interrupted.

## Questions

- Does the Google-hosted management/analytics plane satisfy residency, privacy, support, and third-party controls?
- Do product/lifecycle strengths create measurable value beyond the target catalog and developer needs?
- Can the organization operate supported Kubernetes/runtime versions, Cassandra, upgrades, backup/recovery, capacity, and security economically?
- Is Azure/AKS connectivity and identity integration straightforward enough for the target operating model?
- What is the contractual export/exit path for proxies, products, developer/apps, analytics, and keys?
