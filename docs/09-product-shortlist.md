# Product shortlist and deployment variants

| Variant | Role in assessment | Principal question |
|---|---|---|
| Kong Konnect hybrid | Leading variant | Does SaaS control plus enterprise-hosted data plane meet residency, security, operations, and lifecycle needs? |
| Self-managed Kong hybrid | Leading alternative | Is full control worth database/control-plane and upgrade operations? |
| Azure APIM managed gateway | Azure-native benchmark | Do Azure integration and managed operations outweigh workload distance and platform coupling? |
| Azure APIM self-hosted gateway | Hybrid benchmark | Do feature, workspace, support, and customer-operations boundaries meet federation needs? |
| Apigee X | Enterprise API-product benchmark | Are lifecycle/analytics benefits worth cross-cloud control-plane adoption? |
| Apigee Hybrid | Hybrid enterprise benchmark | Does the richer runtime and its Cassandra/MART operations burden fit the organization? |
| MuleSoft Anypoint | Current baseline | Which capabilities are retained temporarily, replaced, replatformed, or retired? |

Gravitee, Tyk, NGINX Gateway Fabric/Plus, and Istio/Envoy Gateway receive a secondary fit screen; they enter the full PoC only if a finalist fails a mandatory gate or requirements materially change.
