# Networking comparison

For each variant, diagram DNS, edge/WAF, load balancer, gateway addresses, SNAT, firewall, private connectivity, backend paths, management/configuration, telemetry, identity, PKI, registry, and support paths.

Test IPv4/IPv6 requirements, client IP preservation, proxies, private DNS failure, TLS/SNI, connection pooling, idle/total timeouts, HTTP/2/gRPC/WebSocket needs, egress allow-list stability, overlapping address spaces, cross-region latency, and asymmetric routing.

The minimum-privilege flow matrix belongs in `architecture/network-architecture.md`. A vendor diagram is not an organizational network design.
