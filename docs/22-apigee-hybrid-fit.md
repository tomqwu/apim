# Apigee Hybrid fit

## Mandatory exercises

- Install the supported runtime on the exact AKS/Kubernetes version and network model.
- Measure baseline resource footprint and operational toil of Cassandra/MART/runtime services.
- Interrupt management connectivity and validate proxy, restart, configuration, analytics, and reconciliation behavior.
- Upgrade within the published runtime support window and prove rollback/restore.
- Trace data categories and flows to Google services.
- Integrate enterprise IdP, PKI, secrets, logging, metrics, tracing, and private egress controls.

The rich runtime can be an advantage or an operations liability. Decide with a representative installation and staffing/TCO evidence, not a feature checklist.
