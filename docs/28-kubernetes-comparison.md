# Kubernetes comparison

Evaluate installation ownership, supported Kubernetes/AKS versions, CRDs, Gateway API conformance, managed versus unmanaged gateway lifecycle, tenancy, RBAC, namespace delegation, network policy, workload identity, autoscaling, topology spread, PDB, upgrades, rollback, GitOps status, observability, and support boundary.

Kubernetes-native must mean more than "runs in a container." Prefer role-oriented Gateway API resources for portable routing and isolate product-specific policy attachments. Capture controller reconciliation status and reject configurations that are syntactically valid but not accepted/programmed.
