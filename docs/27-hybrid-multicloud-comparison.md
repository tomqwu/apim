# Hybrid and multicloud comparison

Compare the exact location and operator of control plane, request data plane, configuration store, consumer credentials, analytics, portal, audit, backups, and support telemetry.

Measure disconnected proxying, cold restart, clean scale-out, configuration updates, telemetry buffering/loss, certificate/license expiry, version skew, and recovery. Record required inbound/outbound flows and who supports failures at each boundary.

Portability has three layers: portable API contract, portable Kubernetes routing intent, and portable gateway policy. Gateway API improves routing portability but does not make vendor plugins portable.
