# Secondary products

Use a two-week paper screen for Gravitee, Tyk, NGINX Gateway Fabric/Plus, and Istio/Envoy Gateway against mandatory gates: required deployment locations, API lifecycle/product capabilities, identity/security controls, support, Kubernetes/Gateway API fit, audit, disconnected operation, portability, staffing, and commercial viability.

Promote a product to the full PoC only if it uniquely satisfies a requirement, materially improves TCO/operability, or a finalist fails a gate. Service mesh products are not assumed to replace external API management; evaluate the north-south/east-west boundary explicitly.
