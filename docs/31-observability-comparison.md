# Observability comparison

Use the same dashboard and alert contract across products: RED metrics, upstream versus gateway latency, authentication/rate-limit decisions, configuration identity, route/service/consumer dimensions, CP/DP health, resource saturation, certificate expiry, and audit events.

Validate OpenTelemetry/W3C context, Prometheus or equivalent export, SIEM delivery, payload/credential redaction, sampling, cardinality controls, buffering/backpressure, retention, query latency, multi-tenant access, and cost. Missing telemetry during control-plane isolation must be quantified.
