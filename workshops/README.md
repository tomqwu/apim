# Workshop program

Run workshops in sequence, issuing the relevant questions and evidence requests at least five business days beforehand. A facilitator keeps scope and decisions; a scribe records facts, evidence, assumptions, risks, actions, owners, and due dates. Vendor workshops use organization-specific scenarios, not vendor-selected demos.

Each session ends with: decisions made, unknowns, evidence accepted/rejected, matrix criteria affected, actions, and architecture updates. The full bank contains 180 questions.
